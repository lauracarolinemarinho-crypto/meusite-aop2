# Cultura Católica

Site estático em HTML, CSS e JavaScript, com cinco páginas:

- `index.html` — Home
- `historia.html` — História
- `arte-sacra.html` — Arte sacra
- `celebracoes.html` — Celebrações
- `contatos.html` — Contatos e autoria

## Arquivos e pastas

- `styles.css` — estilos compartilhados e responsivos
- `script.js` — abre e fecha o menu em telas pequenas
- `images/` — imagens usadas nas páginas
- `favicon.svg` — ícone do site

Para colocar no GitHub, envie todos os arquivos e pastas deste diretório mantendo essa estrutura. Para usar o GitHub Pages, deixe `index.html` na raiz do repositório.
